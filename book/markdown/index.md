# Weather Regimes — Grams

Analysis and replication of Christian Grams' year-round North
Atlantic–European weather regime classification.

The dataset is published on Zenodo:
[doi:10.5281/zenodo.17080146](https://doi.org/10.5281/zenodo.17080146).
It covers 7 weather regimes (AT, ZO, ScTr, AR, EuBL, ScBL, GL) derived from
ERA5 reanalysis at 3-hourly resolution from 1950 to the present.

## How to read this book

Each chapter is an executed notebook produced by the Snakemake pipeline from
a script in `pipeline/`.
